### 副作用 oracle（三路同时扫） ###
a) service call TvService <N> s16 "probe.p<N>" s16 "VAL<N>"     -> 查 getprop 是否有 probe.p<N>
b) service call TvService <N> s16 "setprop probe.c<N> 1"        -> 查 getprop 是否有 probe.c<N>
c) service call TvService <N> s16 "/sdcard/probe_w<N>" s16 "MARKER" -> 查 /sdcard/probe_w<N>

a) 命中 130 个  (probe.p1 .. probe.p130)        ==> code 1 = systemPropertiesSet
c) 命中 1 个    (/sdcard/probe_w2, 内容 MARKER) ==> code 2 = writeSystemFile
b) 命中 1 个    (probe.c3=1)                    ==> code 3 = runSystemCommand
